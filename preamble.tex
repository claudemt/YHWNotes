% ================================================================
% Book-local extension policy
% ================================================================
% The root preamble owns page layout, numbering, typography, boxes,
% references, generic physics/TikZ styles, the shared theorem
% environments and the coloured theorem palette.  A book may extend
% TikZ or define specialized notation only in content/<book>/settings.tex.
% Do not redefine geometry, headers, captions, hyperlink policy, the
% derivation/exbox/note environments, the theorem environments or
% their colour boxes, or the shared figure styles there.
