# PhysicsLectureNotes 深度重构最终任务包 V3

本包以用户上传的四本原始源码、模范《量子场论讲义》以及用户的 PINEM 论文讲解为依据，目标不是“润色”，而是重新建立四本书的认知顺序、叙述声线和章节边界。

## 文件

- `SKILL.md`：发布级硬规范；新增详实度 A/B/C/D 分级、公式级叙述、模范 QFT 教学动作、删并移拆补重写六类动作和单章验收表。
- `SOURCE_AUDIT.md`：原件源码级审计；新增四书逐章量化表、原件已有好写法、模范 QFT 段落级对照与否决性结构信号。
- `NARRATIVE_REWRITE_GUIDE.md`：段落和公式层面的重写手册，专门把“报告腔/知识库式正文”改成能直接讲出口的小作文。
- `EXECUTION_PROTOCOL.md`：真正改源码时的阶段顺序和每阶段 gate。
- `refactor_AdvancedPhysics.md`：逐原章动作表、关键入口重写顺序、A/B/C/D 深度要求、完整算例与加严验收。
- `refactor_MathSkills.md`：逐原章动作表；谱理论五章重建、分布/PDE/几何/统计的具体叙述入口，以及面向本科基础读者的定义、反例、证明、算例和逐章验收标准。
- `refactor_GroupTheory.md`：逐原章动作表；前六章减重、Lie/根权/Lorentz/Poincaré 从头重建、Example 治理。
- `refactor_FreeElectronQuantumOptics.md`：最激进的重构；逐原章去留、23 章主线、QCD/SM/QFT 百科退出，并从四大力学基础补齐相对论电子、Green 张量、量子光场、偏迹、PINEM、反冲、传播、测量和反演的完整推导链。

## 使用方法

任何线程先读 `SKILL.md → SOURCE_AUDIT.md → NARRATIVE_REWRITE_GUIDE.md → 本书 refactor → 原 issues.md`。

先做结构，后做叙述，再做数学；最后才做图形、排版和源码清理。不要一边拆章一边继续向旧章补内容。

## 最高原则

成书应该像一篇可以连续讲出口的小作文。施工时可以有很严格的表格和清单，但这些施工痕迹不能出现在教材页面上。能用一句自然中文说清楚的逻辑，就不要用框、流程图、粗体提示牌或新 preamble 宏来代替。

V3 进一步固定读者起点：只假定高等数学、线性代数、数学物理方法和四大力学。四册可以互相推荐，但任何一册都不能把另一册当作跳过基础定义、关键证明或当前计算的理由。完成度由读者能否独立复算、指出假设并判断失效条件来检验，不由篇幅、公式数或高级术语数量来检验。
