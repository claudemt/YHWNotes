# 四书深度重构执行协议

这份文件用于真正开始改源码时控制顺序。任何线程都不应一上来“精修文字”或“补公式”，否则会把旧结构继续固化。

## 0. 开工前

必须完整阅读：

1. `SKILL.md`；
2. `SOURCE_AUDIT.md`；
3. `NARRATIVE_REWRITE_GUIDE.md`；
4. 本书 `refactor_<name>.md`；
5. ownership 前后一章原源码；
6. 原 `issues.md`，避免重构把已修正数学错误重新引入。

## 1. Phase A：结构手术

这一轮只决定：删、并、移、拆。

### 允许做

- 新建/拆分 `chXX.tex`；
- 调整 `\input` 顺序；
- 把旁支移附录/source_notes；
- 合并历史 patch 文件；
- 改 chapter/section 标题；
- 更新 dependency map。

### 暂时不要做

- 大规模补新推导；
- 为了衔接写大量临时过渡；
- 新增图；
- 新增 preamble 宏。

### Gate A

只有满足以下条件才进入 Phase B：

- 每个新章能用一句话说出中心问题；
- 没有明显 3000+ 行的多问题巨章；
- 前置理论顺序正确；
- 旁支课程已退出主线；
- 每个旧内容块有明确新归属，没有“先留着再说”。

## 2. Phase B：重写章首、节首和转场

这一轮先不追求数学更多，而是把“为什么现在讲这个”写清楚。

### 每章必须完成

- 章首前 2–5 段重写；
- 每个 section 第一段重写；
- 核心公式前一段和后一段重写；
- 章末转场重写。

### Gate B

朗读测试：随机选章首、最难推导前、章末三处。若需要口头补充“其实这里因为……”，就把补充写回正文。

## 3. Phase C：数学推导审计

按 Skill 的 A/B/C/D 级别处理。

### A 级推导检查单

- 精确起点；
- 新符号；
- 使用的定理/恒等式；
- 中间等式；
- 边界项；
- 变量替换/Jacobian；
- 近似参数；
- 保留阶；
- 误差；
- 量纲；
- 极限检查；
- 物理/几何解释。

### Gate C

执行者能在不查草稿的情况下逐行说明“这一行为什么到下一行”。

## 4. Phase D：完整案例

每个大的理论块至少有一个完整落地计算。案例直接写进正文，不为了案例新增环境。

标准：

> 给定输入 → 调用一般公式 → 代入 → 使用近似 → 算到底 → 检查单位/极限 → 解释结果。

案例不能只做到“代入公式得到数值”。它必须展示理论如何变成实际计算。

## 5. Phase E：语言与术语

统一中文正文；扫描非必要英文、同义术语、报告腔、抽象名词堆积。

重点搜索：

- 母结构、统一框架、统一接口、闭合链；
- 接下来考察、本节将、本章将；
- 显然、容易得到、类似可得；
- ordinary English terms；
- 一次定义大量未来符号。

## 6. Phase F：视觉与工程

最后才清：

- `\boxed`；
- 图字号/遮挡；
- 语义 label；
- hardcoded refs；
- overfull；
- `resizebox/scalebox`；
- dpXX/detail/extra 历史文件；
- preamble 额外命令。

## 7. 每轮提交必须附带的简短记录

不需要写长报告，只记录：

- 本轮处理哪些章；
- 做了哪些删/并/移/拆/补/重写；
- 仍有哪些 A 级推导未审；
- 哪些图/引用/编译问题未闭合；
- 下一轮从哪里继续。

不要把这些维护记录写进正式讲义正文。

## 8. 四书优先级

### FreeElectronQuantumOptics

P0 是身份重构：先把 QCD/SM/QFT 百科退出主线，再拆 ch07–11。若这一点不做，后续所有叙述精修都只是局部改善。

### MathSkills

P0 是 ch04 谱理论重拆和 ch21 统计推断重拆；其次是 ch16–17 场论百科瘦身。

### GroupTheory

P0 是前六章减重、后两章重建。不能只扩 ch07–08。

### AdvancedPhysics

P0 是 ch15 开放系统、ch14 高维量子、ch12–13 连续介质/辐射巨章拆分，以及 ch25 量子电磁场前移。

## 9. 最终判断

如果一次修改让源码更长，但没有让读者更早知道“为什么”，不算进展。

如果一次修改增加了更多结构环境、更多框、更多宏来“提示逻辑”，通常方向错误。

如果一次修改删掉了旁支，却让主线的推导更完整、更连续，这是成功的重构。
